Put your ChatGPT pictures in this folder.

Keep the ID at the start of each file name, for example:
  C01_toaster.png      (cars C01 to C12)
  D01_crumbs_neutral.png, D02_crumbs_win.png   (drivers D01 to D16)

PNG, WEBP or JPG all work. The game picks them up automatically;
anything missing is drawn by the game until you add it.
